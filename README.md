# Korean_Art_Auction
한국 미술 경매 데이터(2017-2021) 분석을 통해 대중적 노출과 작품 가격 간의 직접적 상관성이 희소함을 확인하였으며, 미디어 노출은 작품 단가 상승이 아닌 거래 활성화(입찰 참여도)에 기여한다는 실증적 결론을 도출

Problem (문제 및 가설):

대중적 미디어 노출(노출 빈도)이 미술품 낙찰 가격을 견인할 것이라는 시장 통념에 기반하여 분석 시작.

Pivot (한계 인식 및 전환점):

실제 데이터를 다각도로 검증한 결과, 노출 빈도와 작품 가격 간의 직접적 상관관계(R-squared 등)가 미미함을 확인.

데이터를 왜곡하는 대신, "그렇다면 노출은 시장에서 어떤 진짜 역할을 하는가?"로 분석 질문을 재정의(Pivot).

Proof (재검증 및 인사이트):

가격(Price)이 아닌 거래 유동성(Bidding Count, 유찰률) 및 작가 체급(사후/생존 거장) 변수를 투입하여 재분석.

미디어 노출은 단가 상승이 아닌 ‘거래 성공률 및 시장 저변 확대(Liquidity)’에 기여한다는 실증적 결론 도출.

Lesson (배운 점 및 비즈니스 임팩트):

도메인 특성(미술 시장의 희소성 지배 구조)을 무시한 단순 가설 설정의 한계를 배웠으며, 편향 없는 데이터 탐색을 통해 진짜 비즈니스 레버를 발굴하는 역량을 기름.
